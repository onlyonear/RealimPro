## 4. 生成组验证（可选，自然触发概率低）

报告中的 **#1 生成侧倚音、#3 休止抢拍、#8 冒出 64/128 符头、7.3 三个边界**都只在**生成链路**（点"生成 solo"），导入文件无法触发。

- 这些依赖 `RhythmGenerator` 的特定节奏路径或极端量化，**自然生成很难稳定复现**。
- 建议：不要靠反复手刷；可多次生成、选择节奏密集的设置碰一下，若刷不到属正常——精确触发更适合在未来修复任务里用**单元测试 / 断点**完成。
- 导入与生成是两条独立管线，这一点本身也是报告 7.4 的结论。
