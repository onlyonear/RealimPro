# Real imPro · StoreKit 付费运行时验证步骤（供运行时子代理执行）

- 生成日期：2026-10-10 ｜ 被测构建：即将提交 App Store 的 Release/TestFlight 构建
- 被测 product id：`com.realimpro.master.lifetime`（非消耗型，一次购买终身解锁）
- 前置：工程内**无 .storekit Configuration 文件**。两种测试方式二选一：
  - **方式 A（推荐，最真实）**：用 App Store Connect **沙盒测试账号**（Settings → App Store → Sandboxed Account）。
  - **方式 B（本地，免 ASC）**：Xcode 临时新增一个 StoreKit Configuration，加入同一 product id 并标为 Non-Consumable（**仅本地测试，勿提交入库、勿随包发布**）。
- 通则：每步都记录「操作 → 预期 → 实际 → 通过/失败」；失败截图附时间戳。

---

## 0. 构建验证（先做，对应 PAY-001）

1. 用 **Release** 配置对真机/模拟器做一次 `Build`（`⌘B`，scheme 选 RealimPro，destination 选任一 iOS 设备）。
2. **预期**：编译通过。
3. **若失败**：重点看 `ContentView.swift:2583` / `:2592` 是否报 `type 'ImproAlgorithmGroup' has no member 'master'`。若是，即 PAY-001 成立——**先修（按 findings 示意改逐行判据）再继续后续测试**。
4. 附注：确认 Release 下 `IAPManager` 未把 DEBUG 解锁编进来——方法：Release 构建运行、未登录任何购买时，进入 Grammar 选一位大师点 Generate，**应弹 Paywall 而非直接生成**（若直接生成 = DEBUG 解锁泄漏，立即上报）。

---

## 1. 产品加载（Product Loading）

1. 全新启动 App，选一首免费内置曲（Guide 或 Chord+App）。
2. 切到 Grammar 选一位付费大师（如 CharlieParker）→ 点 Generate。
3. **预期**：弹出 `PaywallView`，标题 "Unlock Master Algorithms"，购买按钮显示 `{本地化价格} — Lifetime`（价格来自 `product.displayPrice`）。
4. 断网重试：无网络时购买按钮区域应显示 "Cannot connect to App Store" + Retry（PaywallView:44-49）。
   - 交叉-本地化核对：此时若触发错误弹窗，记录文案语言（预期英文；若中文即 PAY-002 复现）。

---

## 2. 购买成功（Purchase Success）

1. 联网、登录沙盒账号，在 PaywallView 点购买按钮。
2. 完成沙盒支付确认。
3. **预期**：
   - 购买成功后 `isPurchased=true`，PaywallView 关闭（或 `onUnlock` 回填），不再弹墙。
   - 随后对 9 位大师文法（逐一：LeeMorgan/CharlieParker/BillEvans/JoePass/Cannonball/Chet Baker/Coltrane/Miles/Red Garland）与 2 个 LSTM（Combination/Great Moments）点 Generate，**均直接生成、不再弹 Paywall**。
   - 杀进程重启后仍为已购（entitlement 持久）。

## 3. 购买中途取消（User Cancelled）

1. PaywallView 点购买，在系统确认弹窗点「取消」。
2. **预期**：静默返回，不弹错误（`IAPManager.swift:57-58`），仍未购；再次 Generate 仍弹 Paywall。

## 4. 购买失败 / 网络中断（Failed / Offline）

1. 飞行模式下点购买按钮（或 product 加载失败时点购买）。
2. **预期**：出现错误弹窗（文案语言记录，预期英文），不解锁、不崩。

## 5. 待处理 / Ask to Buy（Pending）

1. 用开启「购买前询问（Ask to Buy）」的沙盒账号发起购买。
2. **预期**：App 提示「待处理」类文案（当前为中文硬编码，记录语言），不立即解锁。
3. 在家长/批准端批准该购买后，**保持 App 在前台**，观察是否经 `Transaction.updates` 自动激活（isPurchased=true、可生成）。
4. 再测：批准时 App 在后台，冷启动后是否自动识别为已购。

## 6. 重复弹窗 / 重复发货（Double-sheet / Double-ship）

1. 已购状态下反复点 Generate、反复进出 PaywallView。
2. **预期**：不重复弹墙、不重复发货；切换大师/LSTM 不出现状态错乱。
3. 核查：购买成功后无「重复扣量」类现象（非消耗型，沙盒账号可重复购买同一 product 属正常，不影响）。

## 7. Restore Purchases（审核常见拒绝点）

1. 换一个**未购**沙盒账号（或删 App 重装模拟未购），进入 PaywallView。
2. 点 **Restore Purchase**。
3. **预期（从未买过）**：提示未找到购买记录（记录文案语言），不解锁、不崩。
4. **预期（曾买过同 Apple ID）**：`AppStore.sync()` 后 `currentEntitlements` 命中，自动解锁、9 大师 + 2 LSTM 可生成。

---

## 8. 老用户更新 / 换机 / 重装自动识别（P0，关键）

1. **基线购买**：用旧版（上一已上架版本）构建 + 沙盒账号 A，完成一次购买，确认解锁。
2. **升级构建**：在同一沙盒账号 A 下，安装**本次新版本**（覆盖安装）。
3. **预期**：启动后**自动识别为已购**，不再次要求付款；9 大师 + 2 LSTM 直接可生成。
4. **换机/恢复设备**：在另一台设备（或抹掉重装）登录同一沙盒账号 A，装本版本。
   - **预期**：自动解锁，无需 Restore（手动 Restore 也应成功）。
5. **product id 一致性核对**：确认旧版与新版使用同一 `com.realimpro.master.lifetime`；若 product id 变过，老用户将无法识别——这是迁移风险点（代码侧本地零键、无需数据迁移，但 id 必须一致）。

---

## 9. 反向白嫖（Un-purchased 状态下逐条跑）

前置：未购沙盒账号 / 全新未购状态。

1. **工具栏 Generate**：选任意大师/LSTM 点 Generate → 应弹 Paywall，不生成。
2. **工具栏 Grammar 下拉点大师**（对应 S1，PAY-001）：点选一位大师 → 记录是否弹墙；随后点 Generate → **必须弹 Paywall**（验证 G2 兜底）。同时观察行尾是否有 `lock.fill`。
3. **设置卡 Grammar 下拉点大师**：点选 → 应弹 Paywall、不切换；行尾有锁图标。
4. **设置卡 Learning 下拉点 LSTM**：点选 → 应弹 Paywall、不切换。
5. **切组进 Learning**（PAY-005）：切到 Learning 组，记录是否静默选中 Combination；再点 Generate → **必须弹 Paywall**。
6. **URL scheme 导入**：用 `irealb://` 或 `irealbook://` 链接唤起/导入（Safari 打开 iReal 链接选本 App，或测试粘贴板/分享）。
   - **预期**：仅导入歌单成功，**不解锁任何大师/LSTM**，不崩；导入后选大师 Generate 仍弹墙。
7. **系统文件导入**：用文件选择器导入一首歌 → 仅导入，不解锁、不崩。
8. **横屏 / 分屏 / Slide Over**：在上述各状态下旋转、分屏，确认付费门仍生效、不崩。
9. **外接键盘**：（本 App 无键盘快捷键，预期无此旁路；若连接键盘后发现任何快捷键直达生成，记录）。
10. **快捷操作**：（本 App 无 Home Screen Quick Action，预期无；如发现长按图标出现动作直达付费功能，记录）。
11. **DEBUG 泄漏**：Release 构建未购状态下，9 大师 + 2 LSTM 全部 Generate → 均须弹 Paywall（任一直接生成 = 泄漏，立即上报）。

## 10. 审核合规检查

1. App 内搜索是否有「外部支付 / 引导网页支付」文案或按钮（PayPal/Stripe/支付宝/微信支付/浏览器购买）。预期：无。
2. 付费功能说明：PaywallView 是否说明「一次性购买、终身解锁」。预期：FeatureRow 已含 "Lifetime access, one-time purchase"。
3. 隐私政策 / 条款（EULA）：确认 App 内（设置/关于/致谢页）有可访问的 Privacy Policy；PaywallView 是否需补链接（对应 PAY-003）。
4. 价格展示：`product.displayPrice` 本地化正确。
5. 错误文案语言一致性（对应 PAY-002）：记录所有错误弹窗语言，应与 App 主语言一致。

---

## 验收判定

- **PASS 门槛**：第 0 步构建通过；第 2/7/8 步购买与老用户识别全部正确；第 9 步未购状态下无任何路径能免费生成大师/LSTM；无外部支付文案。
- **FAIL 即阻塞上架**：
  - 构建失败（PAY-001）；
  - 未购能免费生成任一大师/LSTM；
  - 老用户升级/换机后被重复要求付款；
  - 购买漏发货（成功但不解锁）或重复发货；
  - Release 下 DEBUG 解锁泄漏。
