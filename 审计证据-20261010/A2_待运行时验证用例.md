# Real imPro 待运行时验证用例清单（供模拟器实操）

- 审计日期：2026-10-10
- 用途：每条用例给出可直接构造的输入 + 操作步骤 + 预期，供运行时验证子代理在 iPadOS 模拟器/真机执行，验证本静态审计的推断。

## 一、并发/状态一致性用例（优先验证）

### TC-01｜生成中切歌 → 旧曲 Solo 是否覆盖新曲
- **关联**：STA-001
- **构造方法**：无需特殊文件，用内置曲。
- **操作步骤**：
  1. 侧栏选 `Autumn Leaves`（或任意内置曲）；
  2. 点「生成」，立即在转圈期间（1–3 秒内）侧栏切到 `Blue Bossa`；
  3. 等待 5 秒，观察谱面和弦/音符。
- **预期**：切歌后应显示 Blue Bossa 的内置原旋律，不应出现 Autumn Leaves 的 Solo 音符。
- **实际关注**：谱面是否突然变成另一首歌的音符；播放按钮按下后播的是哪首。

### TC-02｜生成中转调 → 级数/音符是否错位
- **关联**：STA-005
- **构造方法**：内置曲，转调轮盘可用。
- **操作步骤**：
  1. 选一首 C 调内置曲，点生成；
  2. 转圈期间把转调轮盘从 C 转到 F；
  3. 等生成完成，观察级数（# 按钮 / Key Sections）与音符。
- **预期**：级数应按 F 调重新分析；不应出现 C 调生成的音符配 F 调号。

### TC-03｜快速连点两次生成 → 句柄/结果
- **关联**：STA-003
- **操作步骤**：
  1. 选 Learning 组（LSTM，较慢）；
  2. 点生成，转圈期间再点一次生成（或点另一算法）；
  3. 立即退出到侧栏（onDisappear），观察 Console 是否仍有后台任务日志。
- **预期**：第二次生成应正常出结果；退出页面后不应有残留任务继续跑（Debug 日志 `🎵 小节数` 不应在退出后继续打印）。

### TC-04｜生成中退到侧栏再回来 → 谱面是否被清空
- **关联**：STA-002
- **操作步骤**：
  1. 点生成，转圈期间切到侧栏（触发 onDisappear cancel）；
  2. 1 秒后切回原曲。
- **预期**：谱面不应变成白谱（空 generatedSolo）；应回到原曲骨架或内置旋律。

### TC-05｜Original⇄Solo 切换后级数刷新
- **关联**：历史「级数不刷新」缺陷回归
- **操作步骤**：
  1. 生成 Solo 后，点 Original⇄Solo 切换；
  2. 观察级数（# 面板）是否随视图切换刷新。
- **预期**：切换后级数面板应与当前显示的旋律同源，不残留上一首/上一调的分析。

## 二、边界/异常数据用例

### TC-06｜空歌单 / 空和弦序列
- **关联**：边界审计
- **构造方法**：iReal 链接 `irealb://Test/|C|`（无小节）或导入一个内容仅含标题的文件。
- **操作步骤**：导入后选该曲，点生成、点播放。
- **预期**：不崩溃；骨架为空时播放按钮无副作用（`guard !solo.isEmpty`）。

### TC-07｜全 NC（无和弦）小节
- **关联**：IRealProParser 规则8
- **构造 iReal 片段**：`irealb://NoChord/|n|n|n||`（连续 n）。
- **操作步骤**：导入后选曲，切 Guide 组点生成，播放。
- **预期**：全 NC 小节产出整段休止，不崩溃、不长鸣。

### TC-08｜弱起小节 pickup/anacrusis
- **构造 iReal 片段**：以不完整小节开头的经典曲（如 `Autumn Leaves` 自带弱起；或手工构造 `irealb://Pickup/|Cmaj7|Dm7|G7|Cmaj7|` 开头少一个和弦）。
- **操作步骤**：导入后观察小节对齐、播放、五线谱渲染。
- **预期**：首尾小节时值对齐，不出现 measureDurations 越界。

### TC-09｜极长曲目（≥200 小节）
- **构造方法**：用 iReal 链接导入一首超长曲，或循环 `{Cmaj7|Fmaj7|}` 反复 50 次。
- **操作步骤**：选曲，点生成（Guide/Basic/Master/Learning 各一次），播放。
- **预期**：不崩溃；后台生成时间可接受（<10s），不卡死 UI。

### TC-10｜单小节极多和弦（≥8 个）
- **构造 iReal 片段**：`irealb://Busy/|Cmaj7|D7|G7|Em7|A7|Dm7|G7|Cmaj7|`（单小节 8 和弦）。
- **操作步骤**：导入、生成、播放、看五线谱。
- **预期**：不崩溃；小节内和弦时值正确分配。

### TC-11｜损坏/格式不符导入文件
- **构造方法**：
  1. 把一个随机 .txt（非 iReal 格式）拖进文件导入；
  2. 把一个空文件拖进导入；
  3. 把一个 .mxl（压缩 MusicXML）拖进导入。
- **预期**：均弹中文错误提示，不崩溃；.mxl 提示「暂不支持压缩」。

### TC-12｜Malformed MusicXML 空音名（重点）
- **关联**：STA-004
- **构造方法**：手编一个最小 .musicxml：
  ```xml
  <?xml version="1.0"?>
  <score-partwise version="3.1">
    <part-list><score-part id="P1"><part-name>Piano</part-name></score-part></part-list>
    <part id="P1">
      <measure number="1">
        <note><pitch><step></step><octave>4</octave></pitch><duration>4</duration><type>quarter</type></note>
      </measure>
    </part>
  </score-partwise>
  ```
- **操作步骤**：通过「文件」App 导入该文件。
- **预期**：不闪退；提示「MusicXML 中未解析出有效乐曲」或类似错误。
- **当前静态推断**：会在 `MusicXMLQuantizer.pitchMidi:326` 崩溃。

### TC-13｜转调后生成（不同调性）
- **构造方法**：选 C 调曲，转到 F#、Bb 等远关系调，分别生成。
- **预期**：不崩溃；级数按新调分析；五线谱调号正确。

## 三、播放/导出用例

### TC-14｜空片段播放
- **关联**：JazzMidiPlayer 409 行守卫
- **操作步骤**：选一首未生成的骨架曲（无旋律），直接点播放。
- **预期**：不崩溃、不发声或安静返回。

### TC-15｜休止片段 / 跨小节延音播放
- **构造方法**：生成一首含长音符/延音的 Solo，从头播到尾。
- **预期**：不出现长鸣音（isTieStart/isTieEnd 正确收束）；不崩溃。

### TC-16｜极端速度/拍号
- **构造方法**：导入 3/4、6/8、12/8 拍号曲；把 tempo 拉到 40 和 300。
- **操作步骤**：播放、生成。
- **预期**：不崩溃；速度钳制在 40–300（JazzMidiPlayer:416）。

## 四、LSTM / 内存用例

### TC-17｜Learning 组连续生成 5 次
- **关联**：STA-006/007
- **操作步骤**：选 Learning → Combination，连续点生成 5 次（每次不等完成直接点下一次）。
- **预期**：不崩溃、不 OOM；观察 Debug 日志模型加载次数（静态推断：每次都重载 9.1MB）。

### TC-18｜两个 LSTM 模型来回切换
- **操作步骤**：Combination 生成一次 → GreatMoments 生成一次 → 再切回 Combination。
- **预期**：不崩溃；内存峰值可接受（静态推断 ~36MB）。

## 五、付费/本地化交叉用例（浅查）

### TC-19｜未购 Master/Learning 时点生成
- **关联**：交叉-付费
- **操作步骤**：未购买状态下选 Master 文法或 Learning 组，点生成。
- **预期**：弹付费墙，不崩溃、不白嫖（付费逻辑由另一子代理深挖，此处仅确认拦截点不崩）。

### TC-20｜错误提示本地化
- **关联**：交叉-本地化
- **操作步骤**：触发 TC-11/TC-12 导入错误。
- **预期**：错误提示为中文（NSLocalizedString 已包裹），不出现英文裸字符串/崩溃。

## 优先级建议（模拟器先跑）

1. **TC-01**（切歌覆盖）—— 最高频用户路径，最可能复现。
2. **TC-12**（malformed MusicXML 崩溃）—— 唯一可能真实闪退的用例。
3. **TC-02 / TC-05**（转调/切换级数刷新）—— 历史缺陷回归。
4. **TC-03 / TC-04**（任务句柄/清空）—— 验证并发竞态。
5. 其余边界用例作为回归补充。
